/*
    Minidoracat Vehicle Spawn Control: 3D preview helpers, not real vehicles.

    The panel loads a vehicle's model, a chosen paint job and its parts into one of these
    while previewing (client only, reset when the game is re-entered). No spawn zone lists them.
    If the game ever puts one into the world (it replaces vehicles whose type was removed with a
    random type, and admins can spawn any type), the server swaps it for a regular vehicle type as
    it is added to the world (MVSC_Server.lua, S.replacePreviewVehicle). Each is still defined as a
    burnt car shell (model and collision of the vanilla CarNormalBurnt, no paint job, no wheels) so
    that it stays harmless even without that swap.
*/
