description=[h3]By Minidoracat[/h3]
description=
description=[hr][/hr]
description=
description=Adjust how many vehicles spawn in each zone and which ones, from an in-game panel or a config file. Vanilla and modded vehicles are listed automatically.
description=
description=[h2]📦 Requirements[/h2]
description=[list]
description=[*] Required: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3789836701]Minidoracat UI Library for B42[/url] (listed under Required Items; the mod won't load without it)
description=[*] Works in singleplayer and multiplayer; in multiplayer the server must enable this mod
description=[/list]
description=
description=[h2]🚀 Quick start[/h2]
description=[olist]
description=[*] Multiplayer: admins open the vanilla Admin Panel and click the last button, "Vehicle Spawn Control"
description=[*] Singleplayer: right-click the ground and choose "Vehicle Spawn Control"
description=[*] Adjust vehicles or zones and press "Apply changes"; areas generated from then on follow the new settings, while vehicles already in the world stay as they are
description=[*] Rather not open the game? Edit the config file and save it; the change applies automatically
description=[/olist]
description=
description=[h2]✨ Features[/h2]
description=[list]
description=[*] [b]Automatic vehicle list[/b]: vanilla and every modded vehicle, labeled with the mod that adds it
description=[*] [b]Spawn amount[/b]: change each zone's spawn chance and its burnt and special vehicle odds
description=[*] [b]Vehicle mix[/b]: scale a whole mod at once, or tune one vehicle's weight in each zone
description=[*] [b]3D preview and paint swatches[/b]: rotate any vehicle; a game engine limit keeps the 3D preview on the default paint, so every paint job is shown as a swatch
description=[*] [b]Batch edits[/b]: select several vehicles to change multipliers, disable them or add them to zones
description=[*] [b]Config file sync[/b]: save the file and it applies; a mistake keeps the old settings and points to the error
description=[*] [b]History and restore[/b]: see who changed what and roll back to an earlier revision
description=[*] [b]Vanilla permissions[/b]: in multiplayer, only roles with the Sandbox Options permission can make changes
description=[/list]
description=📖 [b]Config file fields, feature details, known limitations and FAQ:[/b] [url=https://steamcommunity.com/workshop/filedetails/discussion/3812410742/586187704184634439/]Vehicle Spawn Control Guide: Panel & Config File[/url]
