description=[h2]✨ What is this?[/h2]
description=Lets server admins list vanilla and modded vehicles automatically and bulk-adjust vehicle spawn amounts and vehicle mix per parking zone, through an admin panel or a config file.
description=
description=[h2]🚧 Development status[/h2]
description=Only the project foundation exists at this time. No in-game features have been implemented yet.
description=
description=[h2]🧰 Planned features[/h2]
description=[list]
description=[*] [b]Automatic discovery[/b]: Lists vanilla vehicles and every vehicle added to parking zones by installed mods when the server starts
description=[*] [b]Spawn amount[/b]: Adjust how often each parking zone gets a vehicle to control the total number of vehicles on the map
description=[*] [b]Vehicle mix[/b]: Adjust how often vehicles appear per mod or per vehicle
description=[*] [b]Admin panel[/b]: Bulk-edit settings in game as an admin
description=[*] [b]Config file[/b]: Or edit the server-side config file directly; changes apply after a restart
description=[/list]
