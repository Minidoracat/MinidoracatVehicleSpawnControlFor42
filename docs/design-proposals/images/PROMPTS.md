# 設計視覺稿 GPT-Image-2 Prompt 集

- 用途：把 `../vehicle-spawn-control.md` 的三個介面候選（A／B／C）與設定檔同步流程畫成可討論的視覺稿。
- 產生方式：Codex 內建 `image_gen`（gpt-image-2），`codex exec` 每張各跑一次；16:9 橫式。
- 風格庫範本（`gpt-image-2-style-library`）：`ui-screenshot-system`（圖 A／B／C；參考 case 17、2、4）、`infographic-engine`（圖 D；參考 case 334、1、8）。
- 共同約束：畫面文字一律繁體中文（腳本名等英數識別字除外）、逐字正確、清晰可讀；數字半形；狀態徽章一律「圖示＋文字」，不可只靠顏色；每張只有一顆琥珀色填色主要按鈕；不得出現真實汽車品牌 logo、真實 Workshop MOD 名稱、浮水印。這些是討論用視覺稿，不是最終 UI 規格——3D 預覽的限制見設計文件「可行性」一節。
- 共同視覺語言（沿用家族 MinidoracatUI 與 Economy 視覺稿）：Project Zomboid 原版 UI 語言——深灰半透明面板、1px 淺灰邊框、白色細字、6px 小圓角、表格斑馬紋極淡；單一琥珀色（約 #FFD966）作為可操作強調色與選取狀態；數字與腳本名使用等寬字體；視窗後方是失焦的 PZ 等角視角廢棄小鎮停車場（灰綠色調、傍晚光線），只作背景。
